# Stock Prediction Lab

An end-to-end learning project for understanding financial markets and building machine learning models for stock-market prediction.

## Project Goal

Learn financial markets, Python, statistics, machine learning, and deep learning by progressively building a stock prediction and backtesting system.

## Learning Path

- Stock-market fundamentals
- Python and Pandas
- Financial data analysis
- Statistics
- Feature engineering
- Machine learning
- Time-series validation
- Backtesting
- PyTorch
- Deep learning
- LSTM/GRU
- Model evaluation
- Deployment

# Stock Prediction Lab

A hands-on project to learn financial markets, Python, machine learning, and deep learning by building a stock-direction prediction pipeline.

## Tech Stack

Python · Pandas · NumPy · Matplotlib · Scikit-learn · XGBoost · PyTorch · Git/GitHub

## Project Roadmap

| Week    | Focus |
| Week 1  | Python, stock data, feature engineering, first ML model |
| Week 2  | Model evaluation and diagnostics |
| Week 3  | Decision Trees and Random Forest |
| Week 4  | Gradient Boosting and XGBoost |
| Week 5  | Time-Series Validation |
| Week 6  | Backtesting and Trading Strategy Evaluation |
| Week 7  | PyTorch Fundamentals |
| Week 8  | Neural Networks |
| Week 9  | LSTM/GRU Time-Series Models |
| Week 10 | Multi-Stock Analysis and Model Comparison |
| Week 11 | Refactoring, Testing, and Application Development |
| Week 12 | Deployment and Portfolio Documentation |

## Project Structure
